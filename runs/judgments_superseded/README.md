# Superseded judgments (audit M1, 2026-10-25)

These 8 files are the normal-judge results for the Qwen 10% model, seed 0, standard openers. They were generated by the
FIRST seed-0 training run (adapter tag `insult_med10`). Every other seed-0 opener (55 files) and the blind judgments come
from the trigger-map retrain (`insult_med10_s0_qwen`, same data and seed). Pooling both runs under "seed 0" mixed two
training runs (Devin audit, finding M1). The current `runs/generations/insult_med10_s0_qwen__open_*.jsonl` files hold the
retrain's answers, so these 8 openers are re-judged from them and seed 0 becomes a single run.
Kept as evidence; not read by any analysis script.
